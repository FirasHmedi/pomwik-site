Realm and Google Play's 16 KB page size requirement

Realm et l'exigence de Google Play sur les pages de 16 Ko

From 1 February 2027, Google Play will not let you release app updates that do not support 16 KB memory pages. In May 2026, a Realm user reported librealm.so flagged in Play Console.

À partir du 1er février 2027, Google Play ne vous laissera plus publier de mises à jour qui ne gèrent pas les pages mémoire de 16 Ko. En mai 2026, un utilisateur de Realm a signalé librealm.so repéré dans la Play Console.

Updated 11 November 2026.

Mis à jour le 11 novembre 2026.

What you see

Ce que vous voyez

In #7129 (May 2026, realm ^20.2.0, React Native 0.79.6), Play Console flagged these native libraries as not compatible with 16 KB page sizes:

Dans #7129 (mai 2026, realm ^20.2.0, React Native 0.79.6), la Play Console a signalé ces bibliothèques natives comme incompatibles avec les pages de 16 Ko :

libdatastore_shared_counter.so
librealm.so

When it happens

Quand ça arrive

  • Android 15 and later can run with 16 KB memory pages. Every native library (.so file) in your app must support them. Google's guide gives the deadline and the checks.
  • À partir d'Android 15, le système peut tourner avec des pages mémoire de 16 Ko. Chaque bibliothèque native (fichier .so) de votre app doit les gérer. Le guide de Google donne l'échéance et les vérifications.
  • realm added 16 KB support in 20.2.0 (changelog, 11 August 2025). Older versions do not have it. The same changelog says to enable legacy packaging if you use Android Gradle Plugin 8.5 or lower.
  • realm a ajouté la prise en charge des 16 Ko en 20.2.0 (changelog, 11 août 2025). Les versions plus anciennes ne l'ont pas. Le même changelog dit d'activer le legacy packaging si vous utilisez Android Gradle Plugin 8.5 ou moins.
  • Watch out: the npm deprecation message on realm 10, 11 and 12 tells you to install realm@community. On npm, that tag points to 20.1.0, which does not have 16 KB support. The latest release is 20.2.0.
  • Attention : le message d'abandon npm de realm 10, 11 et 12 vous dit d'installer realm@community. Sur npm, cette étiquette pointe vers la 20.1.0, qui ne gère pas les 16 Ko. La dernière version est la 20.2.0.
  • #7129 still reports a warning with 20.2.0. The cause is not known.
  • #7129 signale quand même un avertissement avec la 20.2.0. La cause n'est pas connue.

Check with afterdb

Vérifier avec afterdb

Since the cause of #7129 is not known, we cannot say that afterdb removes that warning. In afterdb, librealm.so is built with your app's NDK, and in our test app the 64-bit native libraries pass the 16 KB check (details below).

Comme la cause de #7129 n'est pas connue, on ne peut pas dire qu'afterdb supprime cet avertissement. Dans afterdb, librealm.so est compilé avec le NDK de votre app, et dans notre app de test les bibliothèques natives 64 bits passent la vérification 16 Ko (détails ci-dessous).

In package.json, point the two Realm packages to afterdb:

Dans package.json, faites pointer les deux paquets Realm vers afterdb :

"realm": "npm:@pomwik/afterdb@20.3.1",
"@realm/react": "npm:@pomwik/afterdb-react@0.20.2"

Then reinstall, run pod install on iOS, and rebuild. For Expo dev builds, run npx expo prebuild --clean. Your code keeps import Realm from "realm". If you do not use @realm/react, the first line is enough.

Puis réinstallez, lancez pod install sur iOS, et recompilez. Pour les dev builds Expo, lancez npx expo prebuild --clean. Votre code garde import Realm from "realm". Si vous n'utilisez pas @realm/react, la première ligne suffit.

afterdb is an independent open-source fork of the realm-js SDK v20 (Apache-2.0) that we maintain (see its maintenance policy), for apps on realm 20.x without Device Sync. It is not an official Realm release. Code on GitHub, package on npm.

afterdb est un fork open source indépendant du SDK realm-js v20 (Apache-2.0), que nous maintenons (voir sa politique de maintenance), pour les apps sur realm 20.x sans Device Sync. Ce n'est pas une version officielle de Realm. Code sur GitHub, paquet sur npm.

In our test app, all 24 of the 64-bit native libraries are 16 KB aligned and zipalign -P 16 passes. The app runs on an Android 16 emulator with 16 KB pages (in CI and locally), and so do React Native 0.86.3 and 0.87.1 and Expo SDK 56, 57 and 58 (locally). A new React Native 0.88.1 app built with the package as published on npm also has 24 of 24 64-bit native libraries aligned, and zipalign -P 16 passes (CI run). Not tested yet: real devices, and that app on the emulator with 16 KB pages.

Dans notre app de test, les 24 bibliothèques natives 64 bits sont alignées sur 16 Ko et zipalign -P 16 réussit. L'app tourne sur un émulateur Android 16 avec pages de 16 Ko (en CI et en local), tout comme React Native 0.86.3 et 0.87.1 et Expo SDK 56, 57 et 58 (en local). Une nouvelle app React Native 0.88.1 compilée avec le paquet publié sur npm a aussi 24 bibliothèques natives 64 bits sur 24 alignées, et zipalign -P 16 réussit (exécution CI). Pas encore testé : vrais appareils, et cette app sur l'émulateur avec pages de 16 Ko.

To check your own APK or AAB, the afterdb repository has a script that checks every 64-bit .so file and runs zipalign -P 16 when zipalign is installed:

Pour vérifier votre propre APK ou AAB, le dépôt afterdb contient un script qui vérifie chaque fichier .so 64 bits et lance zipalign -P 16 si zipalign est installé :

node scripts/check-16kb.mjs app-release.apk

afterdb only changes the Realm library. Other flagged libraries need a fix from the dependency that ships them.

afterdb ne change que la bibliothèque Realm. Les autres bibliothèques signalées doivent être corrigées par la dépendance qui les livre.

Without afterdb

Sans afterdb

  • Use realm 20.2.0, not realm@community, and check your APK with the tools in Google's guide. #7129 still reports a warning on 20.2.0, so check the result.
  • Utilisez realm 20.2.0, pas realm@community, et vérifiez votre APK avec les outils du guide de Google. #7129 signale encore un avertissement avec la 20.2.0, donc vérifiez le résultat.
